# peon_kr — 오크 일꾼 (Warcraft III, 한국어)

워크래프트 3 오크 일꾼(Peon)의 한국어 음성을 [CESP v1.0](https://openpeon.com) 이벤트 카테고리에 맞춰 묶은 사운드 팩입니다. 원조 `peon` 팩의 한국어판입니다.

## 설치

```bash
peon packs install peon_kr
peon packs use peon_kr
```

## 카테고리별 음성

### `session.start` (세션 시작)

| 파일 | 대사 |
|------|------|
| `sounds/PeonReady1_KR.wav` | 준비 완료! |
| `sounds/PeonWhat1_KR.wav` | (짧은 대답) |
| `sounds/PeonWhat3_KR.wav` | 무슨 일이죠? |

### `task.acknowledge` (작업 수락)

| 파일 | 대사 |
|------|------|
| `sounds/PeonYes1_KR.wav` | 할 수 있고 말고요. |
| `sounds/PeonYes2_KR.wav` | 기꺼이 하죠. |
| `sounds/PeonYes3_KR.wav` | 일하자, 일. |
| `sounds/PeonYes4_KR.wav` | 좋아요, 좋아. |

| `sounds/PeonYesAttack3_KR.wav` | 그렇게 하죠. |
